# Olist Brazil E-Commerce Analysis

Exploratory data analysis of the Olist Brazilian e-commerce dataset, covering order delivery performance, revenue trends, and customer satisfaction.

## About the Dataset
The Olist dataset contains real, anonymized order data from a Brazilian e-commerce platform, including orders, customers, order items, payments, reviews, products, and seller information.

## Tools Used
- **NumPy** – numerical calculations
- **Pandas** – data cleaning and manipulation
- **Matplotlib & Seaborn** – data visualization

## What This Project Covers
- Cleaning and merging multiple related datasets
- Analyzing delivery times and identifying delayed orders
- Exploring revenue and payment trends
- Visualizing customer review patterns

## How to Run
1. Clone or download this repository
2. Make sure you have the Olist dataset CSV files in the same folder
3. Open `Anusha_Olist_Project.ipynb` in Jupyter Notebook or JupyterLab
4. Run all cells
